What these labels mean
sits on
Lives on that host or service.
beside
Next to it in the stack, not inside it.
runs in
Executes inside that cluster or service.
describes
Names how it’s set up; not a live control.
SSOT
Single source of truth for that setting.
deploys
Puts the change onto the cluster.
optional hop
An extra stop only when that path is turned on.
sidecar
A helper process that rides next to the main service.
webhook
An HTTP callback that triggers a workflow.
public door
The internet-facing entry (n8n’s host).
aggregates
Pulls cost or usage into one view.
